INTRODUCTION                                      *timer-introduction*

Timer.nvim provides two simple utilities:

  • Countdown timers.
  • Stopwatches.

Each timer or stopwatch is displayed in its own floating window and continues
updating while you work.

Multiple timers and stopwatches can run simultaneously.

==============================================================================
COMMANDS                                              *timer-commands*

                                                        *:Timer*
:Timer {duration} [name]

    Starts a new countdown timer.

    {duration} is required.

    [name] is optional. If omitted, a default name is generated using:

        Timer <N>

    where <N> is the next available timer number.

                                                        *:StopTimer*
:StopTimer {name}

    Stops the countdown timer with the given name.

    The timer name is required.

                                                        *:Stopwatch*
:Stopwatch [name]

    Starts a new stopwatch counting upward from 00:00:00.

    [name] is optional. If omitted, a default name is generated using:

        Stopwatch <N>

    where <N> is the next available stopwatch number.

                                                    *:StopStopwatch*
:StopStopwatch {name}

    Stops the stopwatch with the given name.

    The stopwatch name is required.

==============================================================================
DURATION FORMAT                                      *timer-duration*

The |:Timer| command accepts durations consisting of hours, minutes,
and seconds.

Supported units:

    h     Hours
    m     Minutes
    s     Seconds

Units may be combined from largest to smallest.

Examples: >

    20s
    5m
    1h
    20m10s
    1h20m23s
    200s
<

==============================================================================
NAMING                                                  *timer-naming*

Timers and stopwatches are identified by their names.

If no name is provided, Timer.nvim automatically generates one.

Examples:

    Timer 1
    Timer 2
    Timer 3

    Stopwatch 1
    Stopwatch 2

Custom names may also be used.

Examples:

    Study
    Break
    Workout
    Interview

Timer names and stopwatch names are used when stopping them.

==============================================================================
EXAMPLES                                            *timer-examples*

Start a 20 second countdown with an automatically generated name: >

    :Timer 20s
<

Start a named countdown timer: >

    :Timer 25m Study
<

Start another named timer: >

    :Timer 5m Break
<

Stop the "Study" timer: >

    :StopTimer Study
<

Start a stopwatch with an automatically generated name: >

    :Stopwatch
<

Start a named stopwatch: >

    :Stopwatch Workout
<

Stop the "Workout" stopwatch: >

    :StopStopwatch Workout
<
